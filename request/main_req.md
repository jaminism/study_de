1. 개요
- 면접을 위한 객관식, 주관식 문제를 제공하고 푸는 프로그램을 개발
- 각 기술 카테고리의 면접 문제 추출은 하네스 엔지니어링 에서 각 전문가 에이전트가 R&D 를 통해서 수행

2. 환경
- 파이썬
- 웹환경

3. 요구사항
- 데이터 엔지니어 영역의 전반적인 지식에 대해 공부
- 좀더 자세한 기술 스택은 다음과 같음
  - Kafka, Kafka Streams, Spark, Spark Streams, Hadoop, hdfs, hive, trino, iceberg, sql, clickHouse, ElasticSearch, Kibana, Scala, Python, Java, Git, Ranger, Yarn, K8S, REST API 등
